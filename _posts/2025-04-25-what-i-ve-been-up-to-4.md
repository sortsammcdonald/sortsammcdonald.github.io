<p>Typically, my ideas for new projects are either something quite conceptual or practicle[^1]. Lately I've been focusing more on the practicle side, although I've still found some time to continue looking at Haskell. Since my last <a href="https://ql-blog.co/posts/2025-01-22-what_ive_been_up_to/">post</a>, I've updated my <a href="https://github.com/sortsammcdonald/blog_json_update">Markdown to JSON programme</a>. It mostly functions the same as the last version but the code is a bit tidier and it has some nice features like checking for duplicate entries now. Going forward , I would like to archive all the posts form my other <a href="https://sammcdonald.me/miscreviews">blog</a>. I did just notice, it is possible to export the posts directly as JSON files, so some further tweaking to the programme might be required to transform the existing data into the format I want. As far as Haskell goes, I've been working through a new book: <a href="https://pragprog.com/titles/rshaskell/effective-haskell/">Effective Haskell</a>. While I quite enjoy this one, I think it's better to start with <a href="https://people.cs.nott.ac.uk/pszgmh/pih.html">Hutton's book</a>, but once you're done with that, this one is certainly worth a look. As for future aspirations, I'm still very keen at some point to do something this year with graphics and visualisations.
